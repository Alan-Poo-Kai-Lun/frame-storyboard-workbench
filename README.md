# FRAME · 分镜工作台

**把一个故事整理成一组镜头，再把提示词和素材交给视频生成工具。**

你可以在这里写故事、整理人物和场景图片、安排每个镜头的动作与对白，也可以让 AI 帮你规划。基础编辑不需要连接 AI。

提示词就是描述“画面里有什么、怎么动、怎么拍”的文字。FRAME 本身不生成视频。视频在外部工具生成后，可以放回项目中播放、备注和保存。

## 2. 先试一遍，不用配置 AI

1. 在首页点击带 **「官方示例」** 标签的「赛博修仙 v5」，按提示创建示例副本。
2. 点击一个 **片段**，查看这段故事；再点击其中一个 **镜头**，查看动作、对白和提示词。
3. 改一句镜头动作，离开输入框后留意保存状态。节点下方可展开详情，属性面板也可编辑。
4. 点击 **「H3 最终提示词」** 节点，查看并复制该片段的提示词。
5. 想保留一份独立备份，在顶部 **「项目包」→「保存项目备份 / 交接」** 中选择保存项目备份。

完成这几步，你就体验了“看故事 → 改镜头 → 查看提示词 → 保存备份”的基本流程。示例中的视频是已有文件，打开示例不会调用模型或生成新视频。

## 3. 用自己的故事和素材

先认识三个词：**片段**是一小段故事，例如 15 秒；**镜头**是这段故事里的一个画面；**素材**是人物、场景、产品等参考文件。

1. 返回首页，点击 **「创建新项目」** 并命名。
2. 把参考图片拖到画布空白处，加入项目素材。点击素材，填写名称和图片中实际可见的内容，核对后确认说明。
3. 在画布的 **「＋ 添加片段」** 创建一段故事。选中片段，在 **「故事 / 剧本」** 中写下内容；需要引用素材时输入 `@`，从列表选名字。
4. 点击片段旁或卡片内的 **「＋ 添加镜头」**，逐个填写动作、对白与时间。也可以配置 AI 后，让它先规划分镜，预览确认再应用。

例如，先添加“顾客”“店员”“咖啡店”三张素材，再通过 `@` 列表写出：“顾客走进咖啡店，店员点头欢迎，顾客在柜台前停下。”之后把它拆成进店、招呼、回应三个镜头。

**选了 `@` 素材，不代表 AI 已经看过图片。** 图片分析需要另行执行并确认结果；使用自己确认的文字说明时，AI 按这些说明规划。[跟着完整教程做第一个项目](docs/quick-start.md)

画布适合自由排列关系，**「卡片模式」** 适合按片段集中看内容；两种视图编辑的是同一份项目。

## 4. 想让 AI 帮忙时，再连接模型

手动写故事、添加镜头、整理素材和保存项目都不需要模型。AI 拆镜、图片分析和项目对话才需要连接模型服务。

在首页 **齿轮设置 →「AI 连接设置」** 中选择一种方式：

| 方式 | 你需要准备什么 |
|---|---|
| 本机 Ollama | 先运行 Ollama、安装所需模型，再选择实际模型名称 |
| 兼容 API | 服务商提供的接口地址、模型名称和 API Key；费用按服务商规则计算 |

文字规划需要文字模型；分析图片需要支持图片输入的视觉模型。配置完成后测试连接，再使用对应功能。

AI 任务可在 **「任务中心」** 查看。**任务完成后，还要查看结果并确认应用**，才会写入项目。使用云端接口时，请求与相关内容会发送到你配置的服务。[配置与常见问题](docs/faq.md#模型与拆镜)

## 5. 保存项目，还是拿去生成视频？

| 你的目的 | 使用哪个功能 |
|---|---|
| 下次继续编辑，或备份项目 | 「项目包」→「保存项目备份 / 交接」→ 保存项目备份，得到 `.frame.json`；之后从首页导入 |
| 复制文字到外部视频工具 | 在镜头或最终提示词节点中复制提示词，并按目标工具要求准备素材 |
| 交给 ComfyUI 的 H3 导演台 | 点击顶部「导出导演包」，检查后下载 `.mmxpack.zip` |
| 保存已经生成的视频 | 将视频拖入对应的「本片段成片」节点，播放核对、填写备注 |

**导演包不是视频，也不是 ComfyUI 通用工作流。** 目前的接收端是 [AIMixer 的 MiniMax H3 导演台](https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director)：需另行准备它的插件、工作流与模型，再通过导演台内的 **「导入导演包」** 打开文件。[详细对接说明](docs/h3-director-compatibility.md)

如果你还没准备 H3 导演台，先保存项目备份即可。当前版本需要手动导出、导入导演包，尚未提供在工作台内一键调用 ComfyUI 生成视频。

## 常用功能，等需要时再看

- **项目管理**：首页搜索、网格／列表、重命名、复制与回收站；单击选中，双击打开。
- **素材与引用**：输入 `@` 选素材名称，悬停预览；复制图片、粘贴入库和创建副本。
- **AI 辅助**：整篇规划、片段拆镜、写作技能、项目／节点对话；修改先预览再应用。
- **误删恢复**：保存的原规划可恢复缺失片段和镜头，具体操作见教程。
- **外观**：日夜主题、12 套内置方案、自定义配色；微光、探照灯、焊盘和玻璃效果可关闭，支持减少动态。

当前版本统一使用画布／卡片流编辑，已取消独立“详细编辑”页面。[本版更新说明](docs/release-v3.37-beta.1.md) · [完整更新日志](CHANGELOG.md)

## 遇到问题与备份数据

- **打不开、端口占用或媒体黑屏**：[常见问题](docs/faq.md)；不要先删除数据目录。
- **EXE 更新**：备份数据，退出旧启动器，再运行新版 EXE。默认数据目录为 `%LOCALAPPDATA%\FRAME\Workbench\data`。
- **源码更新与迁移**：[安装、更新与数据](docs/install-and-data.md)。源码版默认数据在程序目录的 `data/`。
- **反馈问题**：[提交 Issue](https://github.com/Alan-Poo-Kai-Lun/frame-storyboard-workbench/issues/new/choose)，说明版本、操作步骤和现象；不要上传 API Key 或私人项目。
