# 使用说明 · R15

[首页](../README.md) · [English](quick-start.en.md) · [更新日志](../CHANGELOG.md)

## 启动与更新

从 [Releases](https://github.com/Alan-Poo-Kai-Lun/frame-storyboard-workbench/releases) 下载对应标签的 EXE 或 ZIP。先备份数据并退出旧启动器，再运行新版。新 EXE 放在原 `FRAME-Data` 旁，或在启动器中选择原数据目录；旧版目录按现有迁移机制处理。保持启动器打开，浏览器关闭不代表服务已退出。

源码版先安装 `requirements.txt`，运行 `python server.py`，默认访问 `http://127.0.0.1:8845`。Windows BAT 默认端口 8828，EXE 默认端口 8852；可使用 `--port` 指定其他端口。不要同时启动多个版本争用同一端口。

## 开始一个项目

1. 新建项目，或导入你保存的导演包/项目备份。先尝试手动编辑，无需配置 AI。
2. 添加公共或本组素材，填写说明。右键素材的“AI 与对话”可分析说明或反推提示词；完成后从任务中心查看结果，核对 AI 草稿后再确认。
3. 创建片段，填写故事和时长，展开镜头编辑动作、摄影机、对白、语言及起止空间状态。
4. “自动对齐”整理布局；卡片可拖动、缩放或在设置中调整尺寸。用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。
5. 空画布右键“更多编辑 → 新建 Markdown 笔记”，拖入框内后随框移动和折叠。项目全局笔记用于记录整体要求。
6. 最后镜头后的“H3 最终提示词”可打开独立高亮弹窗。复制到外部生成工具；生成后把视频导入镜头/片段成品区比较。

## 使用 AI

在设置中配置 Ollama 或兼容服务。文字规划使用文字模型，图片分析需要视觉模型。模型请求发送至所配置的服务，云接口费用由服务商收取。

- 整篇剧情规划：左侧设置，右侧输入剧情，先预览后应用。
- 连续性审查：在规划预览中启动 AI 审查，查看身份、地标、逐镜状态与修改对比。仅勾选的建议进入草稿，最后确认才写入画布。
- Agent：输入区顶部拖动条可调整高度。`@` 项目素材或素材库文字说明；引用不代表已实际发送图片、视频或音频。
- 素材库：“加入参考”创建项目副本；“带入 Agent”仅带入讨论，不自动建立画布生成绑定。

## 素材库与复制粘贴

点击媒体预览，直接拖入文件，或在素材库空白处粘贴图片。拖动卡片排序。点击选中后 `Ctrl+C` 复制媒体：图片使用 PNG；Windows 音视频使用文件剪贴板。外部软件需要支持相应格式。输入框内的复制/粘贴仍操作文字。

## 保存与交接

更新和测试前备份数据目录。导演包导出可选包含笔记、Agent 对话、规划草稿与审查记录；阅读 `handoff/README.md`，结构化记录在 `handoff/records.json`，导入时恢复。

API 密钥、连接配置和临时 Agent 附图不随交接记录导出。导出不是完整机器环境或模型的备份，也不保证重复生成相同视频。不要把含私有内容的完整数据目录上传到公开仓库。
