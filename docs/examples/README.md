# 咖啡店入门示例

[下载导演包](cafe-demo.mmxpack.zip) · [逐步教程](../quick-start.md)

这是教学用的 `.mmxpack.zip`，在工作台顶部点击「导入导演包」即可使用。导入会替换当前项目，先备份已有项目。

- 1 个 15 秒片段、3 个镜头，时间分别为 0–5、5–10、10–15 秒。
- Picture 1：人物 A；Picture 2：人物 B；Picture 3：咖啡店。
- 三张图片是用基础形状自绘的 PNG，不对应真实人物或店面。
- 说明由人工编写并人工确认；没有调用 AI，不包含生成视频。
- 经 V3.7 正常导出检查，通过工作台导出并重新导入，3 张素材和 3 个镜头均保留。
- 未在外部 ComfyUI 导演台验证此教学包的生成效果。

用这个示例熟悉“选中镜头 → 修改动作 / 摄影机 / 对白 → H3 Prompt → 导出”的流程。尝试 AI 拆镜前，配置你自己已安装的文字模型。
