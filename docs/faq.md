# 常见问题

[快速入门](quick-start.md) · [返回首页](../README.md)

## 启动与更新

**双击启动后窗口关闭，或者提示找不到 Python？** 在解压目录打开终端，运行 `py -3 --version`（Windows）和 `py -3 server.py` 查看错误。没有 Python 时先安装 Python 3.10+ 并启用 PATH。不要在 ZIP 内运行。

**浏览器提示无法连接？** 保持运行服务器的终端打开，先看终端显示的网址。工作台与 Ollama 是两个服务：工作台默认端口 8787，Ollama 默认 11434。

**8787 被占用？** 在程序目录运行 `py -3 server.py --port 8788`，再访问 `http://127.0.0.1:8788`。其他系统使用 `python3`。

**更新后还是旧版本？** 关闭旧后台，确认启动的是新安装目录中的脚本，查看 `version.json`，浏览器按 Ctrl+F5。桌面快捷方式可能仍指向旧文件夹。`v1.zip` 是固定文件名，不是界面版本。

**下载 GitHub 源码 ZIP 怎么更新？** 源码 ZIP 外面有仓库目录，不能直接替代安装更新 ZIP。首次使用完整解压后直接启动；既有安装先备份 `data/`，正式安装更新 ZIP 按发布说明生成或从 Releases 获取。

## 模型与拆镜

**Ollama 拒绝连接 / WinError 10061？** 确认 Ollama 已启动、服务地址正确。可在终端运行 `ollama list` 查看模型；再到工作台连接设置点“读取 Ollama 模型”。这不代表 ComfyUI 的图片或视频模型已经可用于文字拆镜。

**没有模型？** 工作台不会下载或安装模型。先在模型服务里准备好所需模型；填写实际模型完整名称。视觉分析必须使用支持图片输入的模型。

**有 @Picture 就代表 AI 看过图片了吗？** 不代表。@ 引用负责绑定对象；人工确认说明后，拆镜直接读取说明。要实际看图，先执行素材 AI 分析，再核对并确认使用结果。

**AI 一直运行？** 查看任务中心的当前阶段、耗时与输出量。等待首个输出可能包含模型加载和输入处理。确认没有重复任务，优先使用已确认素材的文字拆镜流程。速度受模型、输出长度和硬件影响，不能保证固定秒数。

**任务完成了但中间没有镜头？** 到任务中心“查看结果”，核对后“应用分镜”。完成记录和应用到项目是两个步骤。

**应用失败 / 来源已变化？** 核对任务提交后是否修改了剧本、素材或上一段。不要盲目覆盖新内容。失败输出保存完整时，可先重新解析，不必重新推理。

**切到下一段为什么还要调整？** 每段有独立故事和本组素材。可复制整段或从其他片段复制素材；公共素材自动共享。文字承接需要上一段的已应用镜头与结束状态。

## 素材、视频与导出

**导演包是给谁用的？** 给 AI 搅拌手（AIMixer）的 H3 导演台，项目为 `ComfyUI_MiniMaxH3_Director`。先自行安装导演台、工作流和模型，然后使用节点里的“导入导演包”。

**直接拖 ZIP 进 ComfyUI，怎么没工作流？** 导演包装的是剧本、时间轴与素材，不是通用节点工作流。先加载作者的导演台工作流，再从导演台导入包。见 [完整对接说明](h3-director-compatibility.md)。

**Picture 编号不同？** 以当前片段显示及 H3 Prompt 中的本片段编号为准。通过 `@` 菜单选素材，不要手动猜全项目编号。

**替换图片影响了其他片段？** 公共素材原本就是共享的。只替换一段时，使用本组素材；替换后重新确认说明。

**导演包导入后缺图？** 保留原包，尝试“素材维护 / 修复 → 修复包内图片”；仍缺失时，将原图拖到缺失卡片替换。包中本来没有的文件无法凭空恢复。

**导出检查阻止下载？** 点检查项定位到对应镜头，先解决时间、媒体和素材问题。智能修复是待核对建议；强制导出不代表修复成功，也不能绕过结构错误。

**视频黑屏？** 先在浏览器直接播放源文件，确认编码兼容，优先 H.264 MP4。检查文件大小限制，以及浏览器下载插件是否拦截 localhost 媒体。

**工作台会生成视频吗？** 不会。视频在外部生成；上传到片段后用于播放、备注和打包记录，不自动剪辑拼接。

**在哪里改视觉参考图片 / GIF / 视频？** 顶部“视觉参考库”或专业参数旁的“图示”进入参考库；在条目上选择“修改 / 替换参考”，或拖入替换。参考库跨项目共享，独立保存在本机，不随导演包复制。
