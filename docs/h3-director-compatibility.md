# 导演包给谁用：AI 搅拌手的 H3 导演台

[返回首页](../README.md) · [工作台入门](quick-start.md) · [常见问题](faq.md)

**FRAME 导出的导演包，目标接收端是 AI 搅拌手（AIMixer）的 ComfyUI MiniMax H3 导演台。**

作者项目：[AIMixer / ComfyUI_MiniMaxH3_Director](https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director)。安装、模型和工作流要求以作者当前说明为准。

## 两种文件，两个导入入口

| 文件 | 内容 | 在哪里打开 |
|---|---|---|
| 作者的 ComfyUI 工作流 JSON | 节点和接线 | 先加载到 ComfyUI 画布 |
| FRAME 的 `.mmxpack.zip` 导演包 | 提示词、时间轴、参考素材及工作台记录 | 再从 **H3 导演台节点内部的「导入导演包」** 打开 |

导演包不能替代 ComfyUI 工作流。不要把包解压出的 `pack.json` 当作节点工作流导入，也不要把 ZIP 直接拖入通用工作流入口期待自动出现节点。

## 在 ComfyUI 中使用前

1. 按作者文档准备支持官方 MiniMax H3 节点的 ComfyUI 环境。
2. 安装 **ComfyUI_MiniMaxH3_Director** 及其依赖，重启 ComfyUI。
3. 加载作者提供的导演台工作流，确认所需模型和节点可用。
4. 然后在导演台内导入 FRAME 导出的包。

**这些依赖由使用者另行准备。** FRAME 不附带导演台插件、工作流、UNET、文本编码器、视频 / 音频 VAE 或模型权重，也不会替用户自动安装它们。工作台本身能启动，不代表外部生成环境已经配置完成。

FRAME 从零新建时的包模板使用 **r2v（参考主体生视频）**。作者说明该模式使用 ref2va 模型；请加载适合 r2v 的导演台工作流并核对模型。导入已有包再编辑时可能保留原任务模式与生成参数，不能只凭文件后缀猜测。

## 导入后先核对，再生成

- 每个素材组中的 Picture 编号，是否对应预期的图片。
- 公共素材与本组素材是否完整，是否存在缺失缩略图。
- 片段顺序、时长、画幅及最终提示词是否正确。
- 任务模式、模型选择、seed、steps、分辨率及段间引导设置是否适合当前工作流。

导入可能覆盖当前导演台时间轴，先保存已有工作。遇到导入失败，保留原包，记录工作台版本、导演台版本 / commit 和完整报错；不要先手改包内素材编号或路径。

## 能导入，也不等于成片会完全一致

导演包记录策划内容与素材，不锁定整套外部运行环境。模型、量化、LoRA、采样配置、插件版本和执行条件改变时，生成结果可能不同。报告可复现问题时，除包外还应附脱敏的工作流、模型名称和版本信息。

没有安装目标导演台时，仍可以使用 FRAME 的素材管理、分镜编辑和 H3 Prompt 文本查看功能；想把文本用于其他工作流，需要自行适配其参考输入和提示词格式，不能承诺导演包直接兼容。

FRAME 是独立的策划与记录工具，目标插件由其作者维护。名称与链接仅说明对接关系，不表示作者认证、联合发布或将第三方代码纳入本项目的权利保留声明。


## V3.15 多媒体与模式

画布选择项目节点后，可在右侧打开「生成模式与输入素材」保存项目任务；MIXED 每段可选 t2v / i2v / fl2v / r2v。v2v / rv2v 使用独立源视频时间线，不作为 MIXED 子模式。模式与各段输入随 FRAME 项目和导演包保存。旧项目保留导入的原模式，直到明确保存新的生成设置。

素材卡支持图片、音频、视频及公共 / 本组作用域。有效公共 + 本组槽位上限为 9 张图片、3 条音频、3 条视频，这是导演台输入协议上限，与独立视觉参考库无容量限制不同。音视频不会编译为图片人物定义。实际模型使用哪些输入由任务类型决定：T2V 不使用参考素材；I2V 使用指定输入图片；FL2V 使用首尾帧；R2V 使用参考素材；V2V / RV2V 使用源视频。

新上传的源视频默认从开头按工作台帧率使用；导入源视频的既有裁剪与 frameMap 保留。成片记录不会自动成为参考或源视频。浏览器能否预览 MOV / MKV 取决于编码，建议 MP4 (H.264/AAC)、WebM、WAV 或 MP3。

验证包括实际 FRAME 导出、工作台往返、本机 Director 导入器在隔离 input 目录解析；没有执行 GPU 采样，不代表每个模式的生成质量已经实测。


## V3.16 画布操作

片段属性可直接选择 T2V / I2V / FL2V / R2V。更改某一段模式时切换 MIXED，其他片段保留原有效模式；V2V / RV2V 仍通过项目生成配置使用源视频时间线。输入未指定时允许保存编辑进度，实际导出会拒绝缺少的 I2V / FL2V 输入。

空白处拖入媒体新增公共参考，拖到镜头或片段卡新增该片段参考，素材卡接受单个同类文件替换，明确成片区域接受成片视频；选择状态不改变投放用途。生成输入不会因拖到镜头上而自动覆盖。

删除素材采用软删除，原媒体和编号保留；可在素材标签的已删除列表恢复。已删除素材若仍被输入绑定或音视频标签引用，导出明确提示修正，避免静默改绑其他素材。

属性自动保存采用校验、必要时重建、写入流程；失败时保留侧栏草稿。外观、布局以小请求保存，并随导演包 sidecar 往返。支持 PCB / HUD 等样式但不改变真实引用方向；最终提示词节点属于当前片段，非全局汇总。
